Read `spec.md`, then compare the current build against it requirement by requirement.

For each requirement, mark its status:
- ✅ **Pass** — requirement is fully met
- 🐛 **Bug** — requirement exists but behaves incorrectly
- ❌ **Missing** — requirement has not been implemented

After the checklist, write a **Repair Brief**: a numbered list of specific, actionable fixes ordered by priority. Each fix must name the file or component to change and describe exactly what needs to be corrected.

If every requirement is ✅, say so clearly — the build matches the spec and no repairs are needed.
